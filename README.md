# Scroll Smith

A self-hosted D&D 5.5 character planner and print-and-play tool for generating physical sheets and card decks (spells, items and features).

## Tech Stack

- **Toolchain:** Vite+ + pnpm
- **Framework:** React + Vite + TypeScript
- **Styling:** Tailwind v4

## Getting Started

### Prerequisites

- Node.js (v20+ recommended)
- pnpm
- Vite+

### Installation & Run

```bash
vp install
vp run dev:api
vp run dev:web
```
